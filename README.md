# Java UML iPhone

A Java object-oriented programming and UML exercise based on an iPhone class model, completed as part of the **Santander Bootcamp 2023**.

## About

This project explores object-oriented programming concepts by modelling iPhone functionality using Java classes and interfaces.

## Technologies

* Java
* Object-Oriented Programming (OOP)
* UML

## Project Status

This project was completed as part of the **Santander Bootcamp 2023** and is no longer under active development.
